Entry for [make.fun's "Make the AI judge feel curious"](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311) ($50).

`main.ts` (Node 22, stdlib only, no network) writes one short text written to intrigue the AI judge reading it to `/output/entry.txt`:

> Somewhere in this building there is a room with no door. The caretaker passes it every morning, keys in hand, and never stops. Tonight the light is on inside — and the only key that fits it has been missing for thirty years.

Run: `node main.ts` (writes `/output/entry.txt`).
